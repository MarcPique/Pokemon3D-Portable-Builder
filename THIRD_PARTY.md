# Third-party projects

This repository does not vendor the runtime dependencies below.

## Gen1Recomp

Upstream: https://github.com/bryanthaboi/gen1recomp

The builder downloads Gen1Recomp during the local build. Consult the upstream
repository for its current notices, supported inputs and terms.

## Dramatic Shape Voxel Mod

Upstream: https://github.com/scottcandy34/DramaticShapeVoxelMod-latest

The upstream README states that redistribution of non-derivative code is
expressly prohibited after v1.6.0 without permission. This repository therefore
does not include, mirror or redistribute the mod source/archive. The builder
downloads it directly from upstream for local use.

## LÖVE

Upstream: https://love2d.org/

The Windows runtime is downloaded during the local build.

## Pokémon content

No Pokémon ROM, extracted ROM data, game graphics, game audio or box artwork
is distributed by this repository.
