# Contributing

Contributions are welcome.

Before opening a pull request:

- do not commit ROMs;
- do not commit ROM-derived generated caches;
- do not commit downloaded dependencies;
- do not commit generated EXEs or release ZIPs;
- do not vendor Dramatic Shape;
- do not commit Pokémon box artwork;
- keep the BAT free of a UTF-8 BOM;
- test runtime changes locally with your own legal ROM.

CI can validate syntax and repository hygiene, but cannot provide a ROM for a
full end-to-end build.
