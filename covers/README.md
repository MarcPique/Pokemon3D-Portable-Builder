# Optional local cover icons

This repository intentionally does not include Pokémon box artwork.

If you have artwork you are legally entitled to use locally, place:

```text
covers/red.jpg
covers/blue.jpg
covers/yellow.jpg
```

The matching image is used for the generated Windows EXE/taskbar icon.

These image files are ignored by Git. If a cover is missing, the builder
continues using the default executable icon.
